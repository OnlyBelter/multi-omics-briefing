# Multi-Omics Daily Briefing

🧬 每日多组学研究简报自动生成工具

## 功能

- 自动搜索 Nature.com 和 ArXiv 最新论文
- 精选 3-5 篇高价值研究
- 生成结构化 Markdown 简报
- 自动推送到 GitHub

## 快速开始

```bash
# 运行生成器
python scripts/generate_briefing.py

# 推送到 GitHub
bash scripts/auto-push-briefing.sh
```

## 定时任务

每天 8:30 AM 自动运行（Asia/Shanghai）

## 输出示例

见 `~/Documents/bioinformatics-frontier/reports/`
